# የጂም መግቢያ ኦፕሬተር መመሪያ (Gym Access Operator Guide)

## 1. የኪዮስክ ስክሪኖች እና ትርጉማቸው (Screen Meanings)
- **Ready to Scan (ግራጫ / Gray)**: ሲስተሙ ለመቃኘት ዝግጁ ነው።
- **Access Granted (አረንጓዴ / Green)**: ትክክለኛ አባል፣ መግባት ይችላል። (በሩ በራሱ ይከፈታል)።
- **ACCESS DENIED (ቀይ / Red)**: መግባት ተከልክሏል። ምክንያቱን በስክሪኑ ላይ ያንብቡ።
- **OFFLINE MODE (ብርቱካንማ / Orange Pulse)**: ኢንተርኔት ተቋርጧል፣ ግን ኪዮስኩ መስራቱን ይቀጥላል። (መስመር ሲመለስ በራሱ ይስተካከላል)።

## 2. የክለከላ ምክንያቶች (Denial Reasons)
- **Unknown ID Card (ያልታወቀ መታወቂያ)**: ካርዱ የዚህ ጂም አይደለም ወይም አልተመዘገበም።
- **Member Blocked (አባል ታግዷል)**: ይህ አባል በአስተዳዳሪ ታግዷል። (የታገደበትን ምክንያት ለመፍታት ማኔጀር ያነጋግሩ)።
- **Membership Expired (የአባልነት ጊዜ አልቋል)**: የአባልነት ክፍያ ጊዜው አልቋል። እባክዎ አዲስ ክፍያ ያስመዝግቡ።
- **Already Checked In Today (ዛሬ አስቀድሞ ገብቷል)**: ይህ አባል ዛሬ አስቀድሞ ገብቷል። (አስፈላጊ ከሆነ በማንዋል ማስገባት ይቻላል)።
- **Gym Closed (Lockdown)**: ጂሙ በአስተዳዳሪ ተዘግቷል። ማንም መግባት አይችልም።

## 3. በማንዋል ማስገባት (Manual Check-in)
ካርዱ ከተበላሸ ወይም ከረሱ፡
1. ወደ **Members** ገፅ ይሂዱ።
2. የአባሉን ስም ይፈልጉ።
3. በአባሉ ፕሮፋይል ላይ **"Manual Check-in"** የሚለውን ይጫኑ።

## 4. ችግር ሲያጋጥም (Troubleshooting)
- ስክሪኑ ከጠፋ ወይም ባርኮድ ካልሰራ: `F5` ተጭነው ፔጁን ሪፍሬሽ ያድርጉ።
- "System Error" ካለ: ኢንተርኔት ወይም ሰርቨሩ መስራቱን ያረጋግጡ። ችግሩ ከቀጠለ ማኔጀሩን ያሳውቁ።
